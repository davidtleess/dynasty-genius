# Dynasty Genius Docs

Use the smallest source that answers the product or engineering question at hand.

- `../PRODUCT.md` — product experience and intent
- `../DESIGN.md` — visual language and interaction principles
- `model-architecture.md` — model structure
- `decision-output-contracts.md` — user-facing output contracts
- `validation/` — model studies, registrations, and reproducibility material
- `superpowers/specs/` and `superpowers/plans/` — historical product designs and build plans
- `strategies/` — dated product and modeling strategy
- `design-audits/` — visual QA records

Historical documents are context, not mandatory startup material. Current product behavior is defined
by the code, tests, `PRODUCT.md`, and `DESIGN.md`.
