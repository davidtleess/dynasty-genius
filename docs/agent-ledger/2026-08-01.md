**THE BUG — my first cut was silently deleting real players.** I keyed rows on
`(season, week, player_id)` and deduped last-wins. That is wrong because
**PlayerProfiler's internal id is initials-plus-a-number and therefore not unique to a

name and team so nothing can overwrite anything; colliding ids get a new
`source_id_collision` status and are **never bridged and never resolved**; and a regression
test asserts stored-row-count equals marker-row-count, since the discrepancy (230,204 vs
