### 🔴 DG-037 — `dg-land.sh` had never once run to completion, and that hid four more bugs

Found by running it, not reading it. `LOCK="$REPO/.git/dg-land.lock"` assumes `$REPO/.git` is a
directory. It is not — `dynasty-genius-product` is itself a **linked worktree**, so its `.git` is a
one-line file. `exec 9>"$LOCK"` died ENOTDIR before the dirty check, the rebase or the tests.
**Nobody ever got far enough to see mechanisms 1–4**, which is why they survived.

Those four are one mistake wearing four hats: **symlinking a directory git needs to see through**.
It produced ~72 phantom deletions per worktree, left the symlinks untracked, broke `git check-ignore`
(*"beyond a symbolic link"*, 13 tests) and broke `Path.relative_to()` (3 tests). The previous
landability fix wrote its exclude to `rev-parse --git-dir` — in a worktree,
`.git/worktrees/<T>/info/exclude`, **a path git never reads**; it reads `--git-common-dir`. That half
silently did nothing while printing `landable : 72 phantom deletions skip-worktree'd`, which read as
success.

Fixed by not creating the shape: a subtree is symlinked whole only when nothing under it is tracked,
otherwise the directory is materialised and its children shared individually. `skip-worktree` and the
per-worktree exclude are **deleted, not repaired**. A self-correcting rule handles the rest — after
symlinking a directory, ask git whether it is ignored, because the repo writes ignores as `foo/` and
a trailing slash never matches a symlink. Total change to shared state: **one line**.

**This falsifies the `✅ SHIPPED — land deadlock FIXED` banner still sitting in `AGENT_SYNC.md`
above `END CURRENT BOARD`.**
