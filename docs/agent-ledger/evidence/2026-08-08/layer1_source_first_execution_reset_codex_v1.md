## New close condition

For every accessible source, a Layer 1 ticket does not close merely because an adapter, contract or
marker exists. It closes only after a governed first acquisition produces:

1. exact raw bytes or a source-authentic raw offering;
2. source and retrieval provenance plus a content hash;
3. a canonical immutable or versioned store appropriate to the source;
4. measured rows/objects and schema;
5. an atomic success/last-good marker;
6. replay/idempotence evidence;
7. consumer migration where an existing direct read already bypasses the store.

Blocked sources close only as honestly blocked, with the missing David/access/legal fact named.
